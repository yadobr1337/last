# Проверка паритета 1VPN Obsidian

Список исходных возможностей и точек входа приведён в [инвентаризации](FEATURE_INVENTORY.md). В колонке «Локальная проверка» указано, насколько глубоко пройден каждый сценарий. Тестовые данные создавались в отдельных SQLite-базах.

| Возможность | Локальная проверка | Проверка на стенде |
| --- | --- | --- |
| Публичные страницы, навигация, тариф, юридические ссылки | Edge проверил главную, меню на телефоне, серверный вывод тарифа и адаптивную обложку. Источники ссылок сверены с исходным кодом. | Соответствие контактов и юридических URL конфигурации стенда. |
| Регистрация и вход | HTTP создал пользователя, проверил некорректный JSON, сессию и вход. Edge проверил форму, минимальную длину, переключатель видимости пароля и выход. | Регистрация с активной hCaptcha. |
| Telegram Widget, Mini App и привязка | Интеграционный тест валидного Telegram-подтверждения и подмены ID. В кабинете сверена форма привязки и исходная ссылка запуска. | Реальный виджет, Mini App, запуск бота и подтверждение связи. |
| Восстановление пароля, email и смена пароля | Edge открыл форму восстановления и профиль. HTTP проверил нейтральный ответ запроса кода. Интеграционный тест подтвердил однократность потребления email-кода. Сверены обработчики полей и условий. | Получение письма, повторная отправка, подтверждение email и пароль на настроенном SMTP. |
| Баланс, оставшееся время и тариф | Edge вывел значения из SQLite. Интеграционные тесты проверили точность тарификации, конкурентные операции и смену тарифа. | — |
| Подписка и подключение | HTTP подтвердил изоляцию чужой ссылки. Edge сверил адрес кнопки подключения и значение в системном буфере. Синхронизация Remnawave проверена на моках. | Подключение тестового клиента через выданную на стенде ссылку. |
| Оплата и история | Edge открыл историю с тестовой проводкой, проверил выбор способа оплаты, состояние с выключенным провайдером, закрытие и возврат фокуса. Интеграционные тесты проверили зачисление по YooKassa, дубли вебхука и откат транзакции. | Переход к тестовому checkout карты и СБП на настроенном стенде. |
| Устройства | Edge изменил лимит через интерфейс. Интеграционный тест проверил расчёт при смене лимита. Команда удаления HWID сверена с исходным обработчиком. | Показ списка, удаление тестового HWID и синхронизация с панелью. |
| Пробный период | Интерфейс сверён с условиями подтверждения Telegram и существующим действием. | Запуск бота и активация пробного периода целиком. |
| Роль ADMIN, обзор и поиск | HTTP проверил роль, бан и отозванную сессию. Edge открыл админку, статистику, тестовый платёж и карточку пользователя. | Данные и счётчики на объёме стенда. |
| Бан, разблокировка, баланс, повторная выдача | Edge открыл и отменил подтверждение бана. Интеграционные тесты проверили конкурентные зачисления и списания. Формы проверены по полям и обработчикам. | Исполнение административных операций для выделенного тестового пользователя. |
| Тарифы, защита и подарочные дни | Edge переключил вкладки клавиатурой, сохранил тариф и начислил день через диалог. Публичный API вернул новую цену. SQLite подтвердила сумму начисления по новому тарифу и лимиту устройств. Интеграционные тесты проверили начисление для разных лимитов. | Включение hCaptcha и редактирование анонса. |
| Технический режим | Edge включил режим и сохранил сообщение. HTTP подтвердил сообщение на главной и доступ администратора. | — |
| Уведомления и рассылка | Edge проверил доступность раздела. Интеграционный тест проверил однократную доставку. Поля текста и фотографии подключены к исходному действию. | Тестовая доставка текста и фото. |
| Remnawave и сквады | Проверена обработка потерянного ответа и сохранение ссылки при синхронизации на моках. Сверены формы и серверные действия. | Проверка подключения, создание и удаление тестового сквада, повторная выдача. |
| Aeza, Timeweb, ноды | Edge открыл раздел. Тесты проверили согласование заказа Aeza и обновление DNS в правильной зоне Timeweb с моками. | Загруженный список нод на стенде и тестовый dry run. |
| Журнал, health, cron и перезапуск | Edge проверил журнал. HTTP проверил health при старте и отказ cron без секрета. Сверено подтверждение перезапуска. | Перезапуск процесса под менеджером на стенде. |
| Адаптивность и доступность | Edge проверил шесть страниц на восьми ширинах, reduced motion, Escape, вкладки, фокус и диалоги. | Safari на iOS и проверка скринридером. |
