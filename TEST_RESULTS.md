# Проверки редизайна 1VPN Obsidian

## Среда и базовый результат

Windows, Node.js 22.22.0, Microsoft Edge в headless-режиме, временные SQLite-базы с миграциями проекта. До редизайна прошли 23 интеграционных теста и HTTP-проверка, включавшая старую главную на 390, 768 и 1440 px.

| Проверка | Результат |
| --- | --- |
| `npm run lint` | ESLint завершился успешно. |
| `npm run typecheck` | TypeScript завершился успешно. |
| `npm test` | 23 из 23. Покрыты биллинг, YooKassa, обход конкурентных дублей, Telegram, email-коды, Remnawave, Aeza, Timeweb и восстановление тестовой SQLite. |
| `npm run build` | Сборка Next.js 16.4.6 завершилась успешно. |
| HTTP-часть `npm run test:http` | Регистрация и невалидный запрос, вход, защита чужой ссылки, роли, заблокированный пользователь, удалённый администратор, нейтральный ответ сброса и отказ cron без секрета. |
| Edge через `npm run test:http` | Завершился успешно. Главная, вход, регистрация, кабинет, профиль и админка без горизонтального скролла на 320, 375, 390, 430, 768, 1024, 1440 и 1920 px. |

## Интерфейс и производительность

Edge проверил SSR цены без дополнительного запроса, правильный WebP на 390 и 1440 px, приоритет изображения, меню, reduced motion, видимость пароля, форму восстановления, вход и выход, URI подключения и значение в буфере обмена, выбор СБП и историю, фокус и Escape. Лимит устройства и тариф сохранены через серверные действия. Админский поиск открыл выдвижную карточку, отмена подтверждения сохранила доступ аккаунта. Через интерфейс на тестовой базе начислен подарочный день и включён технический режим. SQLite подтвердила начисление 106 ₽ для двух устройств по 53 ₽ и флаг технического режима.

WebP обложки занимает 15 654 байта на мобильном и 56 810 байт на десктопе. Полный набор WOFF2 занимает 67 004 байта. Серверные страницы продолжают передавать цены и баланс сразу в HTML. Повторного запроса к `/api/public/settings` с главной при загрузке браузер не зафиксировал. Сравнительные замеры LCP и CLS и тестирование на физических телефонах не проводились.

После запуска сохранённой сборки на localhost разовый замер до первого байта составил 152 мс для главной и 49 мс для входа. Главная, вход, регистрация и health вернули 200. Кабинет и админка вернули ожидаемый 307 для гостя.

# Проверки 1VPN

Проверки запускались локально в Windows на Node.js 22.22.0. Временные базы создавались отдельно от базы приложения. Любые внешние ответы в автоматических сценариях подменяются фикстурами.

| Команда | Фактический результат |
| --- | --- |
| `npm ci` исходной версии и `npm install` после обновления | Установлены зависимости, пересобран `package-lock.json`. |
| `npm run prisma:generate`, `npm run prisma:validate` | Prisma Client 6.19.3 сгенерирован, схема прошла проверку. CLI предупреждает о будущем удалении `package.json#prisma` в Prisma 7. |
| `npm run prisma:deploy` на пустой временной SQLite | Применены исходная и добавочная миграции. |
| `prisma migrate diff` | Схема временной базы после применения миграций совпала с `schema.prisma`. |
| `npm test` | 23 теста прошли. Проверены два одновременных webhook, ошибка БД, завершение процесса до коммита, биллинг, пользователи Remnawave, Telegram, email-коды, неопределённый ответ Aeza и мок Timeweb. Из синтетической WAL-базы восстановлены пользователь, платёж и проводка. После обновления копии `integrity_check` вернул `ok`, нарушение внешнего ключа не обнаружено. |
| `npm run build` | Сборка Next.js 16.4.6 прошла. Главная, кабинет и админка рендерятся на запросе. |
| `npm run lint`, `npm run typecheck` | ESLint и TypeScript прошли без предупреждений линтера. |
| `npm run test:http` | Пройдены регистрация и вход, доступ к собственной подписке, блокировка обычного пользователя на /admin, бан, инвалидирование удалённого администратора и отказ в запуске cron без секрета. |
| `npm run test:http` с `SITE1VPN_BROWSER_EXE` | Edge подтвердил отсутствие горизонтального переполнения главной на 390, 768 и 1440 px, загрузку логотипа с высоким приоритетом, отсутствие повторного запроса цены и вход из формы. |
| `npm audit --omit=dev`, `npm audit` | После обновлений 0 critical, 9 high в production-дереве и 11 high в полном дереве. Порог high оставляет проверку зависимостей в CI красной. |
| `git diff --check`, `sh -n deploy/site1vpn-healthcheck.sh` | Проверка пробельных ошибок и синтаксис скрипта прошли. |
| Поиск секретов в Git | Проверено 39 доступных коммитов. Совпадений по проверенным путям и шаблонам ключей нет. |

При первом запуске Prisma CLI из дочернего процесса тестов Windows получена ошибка Schema engine без деталей. Тесты теперь выполняют тот же SQL миграций через изолированную SQLite. Отдельный `prisma migrate deploy` успешно применил обе миграции. Ошибка записи, видимая в выводе сценария ЮKassa, инициируется тестом и проверяет полный откат.

Windows удерживает часть кэша временного профиля Edge после выхода. Браузерный и HTTP-сценарии завершились с кодом 0. Временная SQLite удалена, предупреждение очистки кэша отображено отдельно.

Оставшиеся high относятся к транзитивным зависимостям Prisma, Remnawave, опциональному SMTP-пакету NextAuth и обработке Source Map. Реальный сервер Nginx/systemd, внешние панели, VPN-клиенты и копия коммерческих данных не проверялись. Сравнимые показатели LCP и размера бандла до изменений не измерялись.
